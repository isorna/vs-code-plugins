# vs-code-plugins

> My plugin repository for development

A personal collection of **Visual Studio Code extensions** built with Node.js and JavaScript, designed to enhance development workflows using AI Agents.

---

## 🧰 Technology Stack

- **Node.js** — Runtime environment
- **JavaScript** — Primary language
- **Agents** — AI-powered capabilities

---

## 📦 Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/isorna/vs-code-plugins.git
   cd vs-code-plugins
   ```

2. **Navigate to the desired plugin folder and package it**

   ```bash
   cd <plugin-name>
   npm run package:vsix
   ```

---

## 🚀 Usage

1. Run the packaging command to generate a `.vsix` file for the desired plugin.
2. Open **Visual Studio Code**.
3. Go to the **Extensions** panel (`Ctrl+Shift+X` / `Cmd+Shift+X`).
4. Click the `···` menu (top-right of the panel) and select **Install from VSIX...**.
5. Choose the generated `.vsix` file and install.
